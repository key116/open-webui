# 游戏卡片路由（Open WebUI 工具插件）

AI 每回合把游戏状态交给这个工具，工具按关键词表自动决定显示哪些卡片组件，按题材词挑皮肤，并把这回合变化的部分高亮出来。AI 只交数据，不挑卡片，所以样式每次都一样。

## 它会做什么

- 关键词 → 组件：字段名里有“金币 / 理智 / HP”就出数值条，有“背包 / inventory”就出道具格，有“地点”就出地点卡，以此类推。中英文、同义词都认，认不出的字段放进“其他信息”，不会丢。
- 题材词 → 皮肤：恐怖、侦探类用暗色档案；中世纪、奇幻、搞笑用羊皮纸；科幻、赛博用终端。
- 对比上一回合：数值旁边显示 +1 / -1，新拿到的道具、新线索带“新”字并发光，没变化的分区收成可点开的小标签。
- 选项按钮：点一下就把整句行动发进聊天，带按压手感和音效。

## 组件和关键词

| 组件 | 认得的字段名（举例） |
|---|---|
| 标题 | 标题、游戏名、title |
| 时间 | 回合、时间、天数、倒计时、turn、time |
| 数值条 | 数值、状态、金币、体面、生命、HP、理智、SAN、幸运…… |
| 地点卡 | 地点、场景、位置、location |
| 事件条 | 事件、提示、消息 |
| 判定卡 | 判定、检定、骰子、roll |
| 道具格 | 背包、物品、道具、inventory |
| 线索条 | 线索、证据、clues |
| 人物 | 人物、角色、NPC |
| 关系 | 关系、好感、信任 |
| 任务清单 | 任务、目标、quests |
| 选项按钮 | 选项、行动、choices |

关键词表和题材表都可以在 Open WebUI 里改（见下面第 7 步），不用动代码。

## 安装步骤（手机上操作）

1. 复制插件代码：用 Safari 打开
   `https://raw.githubusercontent.com/key116/open-webui/feature/game-ui-router/examples/game-ui-router/game_ui_router.py`
   长按页面文字，点“全选”，再点“拷贝”。
2. 打开你的 Open WebUI，用管理员账号登录。界面是英文的话，可以先点左下角头像 → Settings（设置）→ General（通用）→ Language（语言）改成简体中文。
3. 打开左侧边栏，点“工作空间”（Workspace），顶部选“工具”（Tools），点右上角“+”。
4. 名称填“游戏卡片路由”。把代码框里原有的示例代码全部删掉，粘贴第 1 步拷贝的代码，点“保存”。
5. 给模型配上：工作空间 → “模型”（Models）→ 新建或编辑一个模型（比如叫“游戏主持人”），基础模型选你的百炼模型。
   - “工具”一栏勾选“游戏卡片路由”。
   - “系统提示词”里粘贴本目录下 `系统提示词.txt` 的全部内容（Safari 打开 `https://raw.githubusercontent.com/key116/open-webui/feature/game-ui-router/examples/game-ui-router/系统提示词.txt` 拷贝）。
   - 展开“高级参数”，“函数调用”（Function Calling）改成“原生”（Native）。
   - 保存。
6. （可选，推荐）免去确认弹窗：左下角头像 → 设置 → 界面，打开“iframe 沙盒允许同源访问”。不开的话，每次点选项会弹一个确认框，点确认即可。
7. （可选）改关键词或皮肤：工作空间 → 工具 → 找到“游戏卡片路由”，点齿轮图标（Valves），里面的 keyword_map、theme_map 就是两张映射表，可以直接加同义词。

## 试玩

开一个新聊天，选“游戏主持人”模型，发：

> 开一局中世纪搞笑风格的文字冒险，我是种芜菁的农民，数值有金币、体面、奶酪。

正常的话，AI 写几句开场之后会出现一张羊皮纸风格的卡片：顶部是数值，下面是地点、人物、任务，最底下是选项按钮。

## 已知限制

- 对比上一回合的记录存在服务器内存里，Open WebUI 重启后第一回合不会显示 +1 / -1，之后恢复正常。
- 模型要支持工具调用。百炼模型偶尔可能忘了调用，提醒它一句“记得调用 render_game_ui”即可。
- 卡片只用系统字体，不加载外部字体，国内网络也能正常显示。
